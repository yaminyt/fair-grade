# Fair Grade — used phone prices

What used and refurbished smartphones actually sell for, plus buying guides. Static HTML served by GitHub Pages at https://yaminyt.github.io/autophone-ai/.

- `index.html` — price list, budget filter and guide list (the `guides` array in its script).
- `guides/*.html` — standalone buying guides, newest added to the top of the `guides` array.

Prices come from the sources listed on each page; always check the live listing. Do not run `build.py` — it was written for the previous AutoPhone AI page and may overwrite `index.html`.
